# Farmácia "Viva Mais" 💊

Um sistema interativo de linha de comando (CLI) desenvolvido em Python para simular o processo de compra e gestão de carrinho em uma farmácia.

## 🚀 Funcionalidades

* **Catálogo de Produtos:** Exibição de medicamentos disponíveis (Cylocort, Propionato de clobetasol, Dipirona, Neo Soro) com seus respectivos preços.
* **Sistema de Descontos:** Cálculo e aplicação automática de 10% de desconto em produtos promocionais.
* **Carrinho de Compras:** Adição de múltiplos produtos com controle de quantidades.
* **Gestão de Pedido:** Funcionalidade para remover itens específicos ou alterar quantidades antes de fechar o pedido.
* **Cupom Fiscal:** Geração de um recibo detalhado listando os itens comprados, quantidades, subtotais e o valor total a pagar.
* **Tratamento de Erros:** Validação contínua das entradas do usuário (evitando que o programa quebre ao digitar letras em vez de números).

## 🛠️ Tecnologias Utilizadas

* **Python 3.x:** Linguagem base utilizada para toda a lógica do projeto.
